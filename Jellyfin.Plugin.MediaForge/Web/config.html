MediaForge Requests

Die Verbindung läuft ausschließlich vom Jellyfin-Server zu MediaForge. Ein gespeicherter API-Schlüssel wird verschlüsselt abgelegt und nicht wieder an den Browser ausgegeben.

Vom Jellyfin-Server erreichbare Basis-URL, gegebenenfalls inklusive Reverse-Proxy-Pfad.
Der Key wird verschlüsselt gespeichert und nie wieder an den Browser ausgegeben. Benötigte Scopes: status:read, library:read, queue:read und queue:write.
Aus: Benutzeranfragen bleiben ausstehend, bis ein Jellyfin-Administrator sie freigibt. An: gültige Anfragen gehen sofort an MediaForge.
Nach einer Änderung müssen bereits geöffnete Jellyfin-Webseiten neu geladen werden. File Transformation wird unterstützt; ohne dieses Plugin wird index.html als Fallback angepasst.
Kommagetrennte MediaForge-Quellen-IDs. Leer bedeutet: alle aktivierten, nicht anderweitig gesperrten Quellen.
Begrenzt parallele Anfragen an externe Kataloge.
